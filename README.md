# AutoValue AI — прогнозирование стоимости автомобилей

## О проекте

Учебный проект по оценке стоимости подержанных автомобилей для сервиса мгновенного выкупа. Задача — построить модель, которая оценивает стоимость автомобиля, и выбрать алгоритм с учётом как точности прогноза, так и бизнес-рисков завышения и занижения цены.

## Бизнес-задача

Сервису нужна быстрая оценка автомобиля по его характеристикам. Ошибки оценки имеют разную стоимость для бизнеса: завышенная цена может снижать привлекательность предложения, а заниженная — приводить к финансовым потерям при выкупе.

**Основная метрика качества:** MAE. Дополнительно анализировались RMSE, R², Overpricing Rate и Underpricing Loss.

## Что сделано

- Проведён исследовательский анализ данных, в том числе анализ связей между признаками с помощью PhiK.
- Подготовлены признаки для моделей градиентного бустинга.
- Обучены и сравнены CatBoost, XGBoost и LightGBM.
- Подобраны гиперпараметры с помощью Optuna.
- Исследован подход CatBoost с Quantile Loss для изменения компромисса между типами ошибок.
- Использован SHAP для интерпретации предсказаний.
- Проанализированы ошибки и бизнес-метрики по маркам автомобилей и регионам.
- Лучшая модель дополнительно оценена на отложенной тестовой выборке.

## Инструменты

Python, pandas, NumPy, scikit-learn, CatBoost, XGBoost, LightGBM, Optuna, SHAP, PhiK, Matplotlib, Seaborn.

## Сравнение оптимизированных моделей

Результаты на валидационной выборке после подбора гиперпараметров с помощью Optuna:

| Модель | MAE, руб. ↓ | RMSE, руб. ↓ | R² ↑ | Overpricing Rate ↓ | Underpricing Loss, руб. ↓ |
|---|---:|---:|---:|---:|---:|
| **CatBoost** | **79 228** | **98 954** | **0.8554** | 13.63% | **17 464 747** |
| XGBoost | 80 374 | 100 847 | 0.8498 | **13.25%** | 19 334 325 |
| LightGBM | 80 820 | 101 477 | 0.8480 | 13.56% | 20 548 204 |

### Вывод по сравнению

CatBoost показал лучшие результаты по MAE, RMSE и R², а также наименьший Underpricing Loss среди оптимизированных моделей. XGBoost продемонстрировал меньший Overpricing Rate. Поэтому CatBoost выбран основным кандидатом по совокупности метрик, но окончательное бизнес-решение зависит от относительной стоимости завышения и занижения цены.

Значения бизнес-метрик следует трактовать с учётом формул, реализованных в ноутбуке. Время обучения и предсказания зависит от оборудования и окружения.

## Запуск локально

Создайте виртуальное окружение, установите зависимости и запустите Jupyter:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter lab
```

Откройте `notebooks/autovalue_car_price_prediction.ipynb`. Перед запуском убедитесь, что разрешённые исходные данные находятся в `data/`. Версии библиотек в `requirements.txt` являются ориентировочными и могут потребовать проверки совместимости с исходным окружением проекта.

## Ограничения

Проект является учебным. Метрики получены на предоставленных учебных данных и сами по себе не подтверждают готовность модели к промышленному использованию. Для внедрения потребовались бы дополнительные проверки качества данных, устойчивости модели, бизнес-порогов и мониторинга после запуска.
