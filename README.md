# AutoValue AI — прогнозирование стоимости автомобилей

## О проекте

Учебный проект по оценке стоимости подержанных автомобилей для сервиса мгновенного выкупа. Цель — сравнить модели градиентного бустинга и выбрать модель с учётом качества прогноза и бизнес-рисков, связанных с завышением или занижением цены.

## Задачи

- Провести исследовательский анализ данных.
- Подготовить признаки для моделей градиентного бустинга.
- Сравнить CatBoost, LightGBM и XGBoost.
- Настроить гиперпараметры с помощью Optuna.
- Интерпретировать прогнозы с помощью SHAP.
- Проанализировать ошибки и бизнес-метрики по маркам автомобилей и регионам.
- Оценить выбранную модель на отложенной тестовой выборке.

## Инструменты

Python, pandas, NumPy, scikit-learn, CatBoost, XGBoost, LightGBM, Optuna, SHAP, PhiK, Matplotlib, Seaborn.

## Результаты

Оптимизированная модель CatBoost показала на тестовой выборке:

| Метрика | Результат |
|---|---:|
| MAE | 75 601 руб. |
| RMSE | 94 980 руб. |
| R² | 0.8744 |
| Overpricing Rate | 13.30% |
| Underpricing Loss | 19 798 539 руб. |

CatBoost выбран как основной кандидат по совокупности стандартных метрик и Underpricing Loss. При этом XGBoost показал меньший Overpricing Rate, поэтому окончательный выбор зависит от относительной стоимости разных типов ошибок. Значения бизнес-метрик следует интерпретировать с учётом формул, реализованных в ноутбуке.

## Запуск локально

Создайте виртуальное окружение, установите зависимости и запустите Jupyter. Версии библиотек в `requirements.txt` являются ориентировочными и требуют проверки совместимости с исходным окружением проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter lab
```

Откройте `notebooks/autovalue_car_price_prediction.ipynb`. Перед запуском убедитесь, что разрешённые исходные данные находятся в `data/`.
